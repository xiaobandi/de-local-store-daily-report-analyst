## 示例二 · 用你自己的材料

```bash
python3 ../../tools/anomaly_detect.py --file /path/to/your-data/metrics.json
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/anomaly_detect.py --file examples/input/metrics.json || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。

---

## 质量自检（交付前必过）

- [ ] 所有异常都给了业务解释字段（哪怕是'待查'）
- [ ] 各步产出按顺序衔接，链路无断点
- [ ] 缺料时显式停下来问，未用假设填补
