# 使用示例

技能：**日报生成**（`wf-local-daily-report`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/brief_render.py --kind brief --file examples/input/brief.json --title '今日经营简报'
```

**真实输出**：

```console
# 今日经营简报

> 生成日期：2026-09-30　格式：brief

**一句话结论**：今日 GMV 1.29 万，环比 +52%，主要由单品秒杀拉动

## 关键数据

| 指标 | 数值 |
|---|---|
| 成交额 | 12,900 |
| 订单数 | 86 |
| 客单价 | 150 |
| 退款率 | 2.1% |

## 高光 / 亮点

- 秒杀单品转化率 6.8%，为日常 2 倍

## 风险与阻塞

- 秒杀后库存仅剩 37 件，明日可能断货

## 下一步动作

- 今日 18:00 前补库存
- 将秒杀款加入明日排期
```

> 结构化数据一次渲染为可直发团队的简报骨架，缺口显式留空

> **注意**：渲染器**不负责编造内容**——未提供的段落会留「待填」标记，避免空话填空。

---

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/brief_render.py --kind brief --file /path/to/your-data/brief.json --title '今日经营简报'
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/brief_render.py --kind brief --file examples/input/brief.json --title '今日经营简报' || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
