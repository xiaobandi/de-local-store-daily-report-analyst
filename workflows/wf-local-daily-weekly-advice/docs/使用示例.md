# 周建议 · 使用示例

> 本页只放**真实执行过**的输入与产出。没有执行证据的地方显式标 `⚠️ 尚未补齐`，不用模板文本凑数。

⚠️ 尚未补齐

本工作流**尚无真实执行记录**，因此这里不放示例——放了就是编的。

### 怎么补

1. 准备一份真实材料，放到 `examples/input/`；
2. 按 `SKILL.md` 的步骤跑一遍，把原始产出存到 `examples/output/session.txt`；
3. 把「输入摘要 → 产出摘要」写进本页，并注明材料日期与执行环境。

参考做法：本仓 `docs/05-验收与测试.md` 的记录口径，以及 `agent-skills-library/docs/发布标准.md` 第二节第 2 项。

## 输入字段速查

| 项 | 内容 |
|---|---|
| 必需 | 本工作流的起始材料（见 `SKILL.md`「执行步骤」第 1 步）；用户身份与目标平台/渠道 |
| 可选 | 历史产出；账号人设；渠道规则；上一周期的数据 |
| 产出 | 下周一个重点动作 |
