# 周建议 · 架构与流程图

## 本工作流的四层结构

```mermaid
flowchart TB
  U["使用层：门店经营日报分析师 的使用者"]
  T["触发层：周建议"]
  X["执行层：2 个步骤"]
  O["产出层：下周一个重点动作"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 全部门店（受众最广）；员工定位：每天打烊后一句话告诉老板"今天生意怎么样、明天注意什么" |
| 触发层 | 关键词 / 显式点名「周建议」；触发方式：定时（每周一） |
| 执行层 | 周趋势 → 下周一个重点动作 |
| 产出层 | 下周一个重点动作 |
