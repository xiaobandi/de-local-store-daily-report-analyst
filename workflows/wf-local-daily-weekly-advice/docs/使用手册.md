# 周建议 · 使用手册

> 工作流 `wf-local-daily-weekly-advice`　·　归属 **门店经营日报分析师**（`de-local-store-daily-report-analyst`）　·　复杂度 S　·　阶段 P1

**一句话**：周趋势 → 下周一个重点动作

## 一、装到各平台

| 平台 | 安装方式 |
|---|---|
| WorkBuddy | 把技能目录放到 `~/.workbuddy/skills/`，或直接在对话里说触发词 |
| ChatGPT | 打包为 zip 后在 Skills 设置里上传（需支持 Skills 的版本） |
| DeepSeek Harness | `新建技能 安装:<repo-url>`，或把目录放进 harness 的 skills 目录 |
| Kimi Work | 上传 zip 或放置到技能目录；Kimi Work 不保证自动触发，建议显式点名 |
| 豆包工作 | `新建技能 安装:<repo-url>`，或在技能管理处上传 zip |

> 本包是**自包含**目录：把 `wf-local-daily-weekly-advice/` 整个目录拷到平台的技能目录即可，不依赖兄弟目录。跨平台加载约定：`<项目>/.agents/skills/<name>/`、`~/.agents/skills/<name>/`，项目级覆盖用户级。

### 装不上怎么办

| 项 | 内容 |
|---|---|
| 目录名与 `name` 不一致 | 本包目录名必须与 frontmatter 的 `name` 逐字相同（应为 `wf-local-daily-weekly-advice`），改名后平台才认得出 |
| 放进去了但不触发 | 触发靠 `description`：先说关键词，或**显式点名**「用 周建议 处理这份材料」 |
| 提示缺少脚本 | 本包不带 `scripts/`；该能力依赖本仓 `tools/` 下的共享脚本，请从仓库根运行 |
| 中文乱码 | 以 UTF-8 打开；Windows 终端用 `chcp 65001` |

## 二、怎么触发它

- **关键词触发**：`wf wf-local-daily-weekly-advice`、`周建议`
- **显式点名**：「用「周建议」处理这份材料：<粘贴或指向文件>」
- **触发方式（注册表口径）**：定时（每周一）

> 触发责任全部写在 `description` 里。关键词只是最省事的路径，意图吻合时也会触发。

## 三、输入契约

**必需**：

- 本工作流的起始材料（见 `SKILL.md`「执行步骤」第 1 步）
- 用户身份与目标平台/渠道

**可选**：

- 历史产出
- 账号人设
- 渠道规则
- 上一周期的数据

**缺必需输入时的行为**：停下来问，明确说出缺什么；**不允许**用假设补全。

## 四、产出长什么样

下周一个重点动作

逐步产出：

1. **周趋势** — 产出该步的结构化结果（四要素：输入来源 / 产出 / 依据与结论 / 未决·待填）
2. **下周一个重点动作** — 产出该步的结构化结果（四要素：输入来源 / 产出 / 依据与结论 / 未决·待填）

## 五、依赖与运行环境

| 项 | 内容 |
|---|---|
| 平台能力 | 读取工作区文件（必需）；执行代码、联网检索（可选，缺失时走降级路径） |
| 自带脚本 | 无（纯提示词技能，规则全部写在 `SKILL.md` 正文） |
| 外部依赖 | 无第三方包；不硬编码任何厂商接口 |
| 知识库 | 本员工知识库 `kb/`（见 `de-local-store-daily-report-analyst/kb/README.md`） |
| 连接器 | 只读优先；写操作一律需人工确认（见本仓 `connectors/bindings.yaml`） |

## 六、数据与权限声明

| 项 | 内容 |
|---|---|
| 读取 | 工作区内用户提供的材料；本员工 `kb/` 语料 |
| 写入 | 仅工作区产出文件；**不写**任何外部系统 |
| 联网 | 默认不联网；需要外部事实时标注「需查证」交人工 |
| 个人信息 | 手机号/地址/订单号等一律先脱敏再进入产出 |
| 对外发布 | **本工作流不代替人工点击发布**，对外内容必须经人工确认闸门 |
| 密钥 | 不接收、不存储、不落盘任何密钥 |

## 七、常见问题

| 项 | 内容 |
|---|---|
| 产出里出现 `<待填>` | 这是**正确行为**：输入里没有的数字不许估算，按「未决·待填」清单补材料后重跑 |
| 和预期结果不一致 | 先核对输入是否落在「输入契约」范围内；范围外属不适用场景 |
| 中途想改方向 | 停下来说明新目标；本工作流按新输入重跑，不在此基础上叠改 |
